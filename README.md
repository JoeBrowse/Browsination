# Browsination

Personal life manager. React + TypeScript + Vite, SQLite, Capacitor Android.

```
npm install
npm run dev      # desktop browser
npm run check    # typecheck, lint, tests
```

APKs: every push to `main` builds one (Actions artifact); every `stage-*` tag attaches one to a GitHub Release. See `CLAUDE.md` for architecture and conventions, `PROGRESS.md` for stage status and decisions.
